# Excel Data Analysis and Reporting

This repository contains practical Microsoft Excel projects focused on data analysis, formulas, lookup functions, PivotTables, reporting, and data handling.

## Projects

### 1. Excel Functions and Data Reporting
**File:** `Excel_Functions_and_Data_Reporting.xlsx`

Practical Excel exercises involving:
- VLOOKUP and lookup-based data retrieval
- IF and IFERROR functions
- SUMIF and SUMIFS
- COUNTIF and COUNTIFS
- SUBTOTAL
- Filtering and data handling
- Attendance and percentage calculations
- ROUND, ROUNDUP, and ROUNDDOWN
- Working with structured and larger datasets

### 2. Excel Data Analysis and PivotTable
**File:** `Excel_Data_Analysis_and_PivotTable.xlsx`

Practical data analysis exercises involving:
- PivotTables
- VLOOKUP
- IF and AND functions
- IFERROR
- Goal Seek
- Dataset analysis and summarization
- Excel-based reporting
